# HW-06b – Triangle Classification Testing

**Course:** SSW 567 – Software Quality Assurance  
**Author:** Mahima Jain

## Assignment Description

The objective of this assignment is to develop test cases for an existing triangle classification program, identify and fix defects in the program, and report the testing results.

## Files

- **Triangle.py:** Contains the triangle classification function provided for the assignment.
- **TestTriangle.py:** Contains the unit tests used to test the triangle classification function.

## Running the Tests

The test cases are executed using Python's unittest framework.

```bash
python -m unittest TestTriangle
```

## Assignment Process

1. Commit the original Triangle.py and TestTriangle.py files.
2. Enhance the test cases without modifying Triangle.py.
3. Run the tests and document the initial results.
4. Fix defects in Triangle.py.
5. Run the tests again and document the final results.
